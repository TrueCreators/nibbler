# Nibbler

Nibbler - это проект Змейки с тремя разными графическими библиотеками, которые подключаются динамически во время выполнения.

## Описание

Проект разделен на 4 части:
1. Основной исполняемый файл - отвечает за игровую логику
2. Три динамические библиотеки:
   - SDL
   - Raylib
   - SFML

Основой игры является классическая Змейка, где игрок управляет змеей, собирая еду и избегая столкновений с собой и стенами. Уникальность этого проекта заключается в возможности переключения между тремя разными графическими библиотеками во время игры.

## Требования

- C++ компилятор с поддержкой C++11
- Библиотеки SDL2, SDL2_image и SDL2_ttf
- Библиотека Raylib
- Библиотека SFML
- make

## Установка

Для установки всех необходимых зависимостей запустите скрипт установки:

```bash
cd scripts
chmod +x install_dependencies.sh
./install_dependencies.sh
```

## Компиляция

```bash
make
```

## Запуск

```bash
./nibbler <ширина> <высота>
```

где:
- `<ширина>` - ширина игрового поля (от 10 до 100)
- `<высота>` - высота игрового поля (от 10 до 100)

Пример:
```bash
./nibbler 20 20
```

## Управление

- Стрелки: управление змейкой
- 1, 2, 3: переключение между графическими библиотеками
- ESC: выход из игры

## Архитектура

Проект построен с использованием принципов объектно-ориентированного программирования и динамического подключения библиотек.

Основные компоненты:
- `Game`: управляет игровой логикой
- `Snake`: представляет змейку
- `Food`: представляет еду
- `DynamicLoader`: обработчик динамических библиотек
- `IGraphicsLib`: интерфейс для графических библиотек

Каждая графическая библиотека реализует интерфейс `IGraphicsLib`, что позволяет основному исполняемому файлу работать с ними единообразно. # nibbler
