# Руководство по установке Nibbler

Это руководство описывает процесс установки проекта Nibbler без прав администратора (sudo).

## Требования

Для компиляции и запуска проекта вам потребуются следующие инструменты:
- gcc/g++ (поддержка C++11)
- make
- git
- wget
- tar
- cmake

## Установка зависимостей

Проект Nibbler использует три графические библиотеки:
- SDL2 (с SDL2_image и SDL2_ttf)
- SFML
- Raylib

Для установки библиотек без использования прав администратора (sudo), выполните:

```bash
cd scripts
chmod +x install_dependencies_no_sudo.sh
./install_dependencies_no_sudo.sh
```

Этот скрипт:
1. Скачает и скомпилирует все необходимые библиотеки из исходников
2. Установит их в директорию проекта (./libs/)
3. Создаст файл настроек окружения (nibbler_env.sh)
4. Создаст скрипт для запуска проекта (run_nibbler.sh)

## Сборка проекта

После установки зависимостей вы можете собрать проект:

```bash
# Используя скрипт сборки
cd scripts
chmod +x build_and_run.sh
./build_and_run.sh build

# Или вручную
source ./nibbler_env.sh
make
```

## Запуск проекта

Для запуска проекта вы можете использовать:

```bash
# Используя скрипт запуска
./run_nibbler.sh 20 20

# Или скрипт сборки и запуска
cd scripts
./build_and_run.sh run 20 20

# Или вручную
source ./nibbler_env.sh
./nibbler 20 20
```

Где 20 20 - это ширина и высота игрового поля (должны быть в диапазоне от 10 до 100).

## Управление в игре

- Стрелки: управление змейкой
- 1, 2, 3: переключение между графическими библиотеками
- ESC: выход из игры

## Возможные проблемы и их решение

### Проблемы с библиотеками

Если у вас возникают ошибки с загрузкой библиотек во время запуска, проверьте:
- Был ли правильно запущен скрипт установки зависимостей
- Загружены ли переменные окружения (source ./nibbler_env.sh)
- Созданы ли символические ссылки на библиотеки в корневой директории проекта

Для переустановки библиотек выполните:
```bash
make cleanlibs
./scripts/install_dependencies_no_sudo.sh
```

### Проблемы с компиляцией

Если у вас возникают проблемы с компиляцией проекта:
- Проверьте наличие всех необходимых инструментов (gcc, make, cmake)
- Проверьте правильность установки библиотек
- Проверьте, загружены ли переменные окружения (source ./nibbler_env.sh)

Для полной очистки и пересборки проекта выполните:
```bash
make fclean
source ./nibbler_env.sh
make
```
